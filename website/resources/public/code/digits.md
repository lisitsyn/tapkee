In this example a set of procedurally generated handwritten-digit-style
glyphs (28 x 28 images, digits 0-9) is embedded using the t-SNE method.
Each image is represented by a 784 dimensional vector (one feature per
pixel). The dimension reduction method attempts to group vectors which
represent the same digit (in an unsupervised manner — no labels are
provided) in 2d space.

The dataset is generated by `website/tools/generate_digits.py` and is
original artwork created for this demo: reproducing this example with
real MNIST digits would mean downloading that dataset from a third-party
mirror at every build, an external dependency this site's build
otherwise doesn't have.

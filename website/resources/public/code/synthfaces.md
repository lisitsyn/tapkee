In this example we embed a set of procedurally generated
cartoon face images (40 x 40 pixels). Each face is rendered
from two continuous parameters: head turn and expression.
The Local Tangent Space Alignment method is used to embed
the data to 2d euclidean space. It is worth noting that
the images have an intrinsic dimensionality of 2, which
is recovered by the algorithm from pixel data alone.

The dataset is generated by `website/tools/generate_synthfaces.py`
and is original artwork created for this demo (no external
face database is used or redistributed here).
